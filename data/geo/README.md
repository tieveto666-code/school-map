# 中国地图 GeoJSON 说明

## 文件

| 文件 | 说明 |
|------|------|
| `china.json` | 省级行政区划 GeoJSON（35 个省级单元），供 ECharts 地图渲染 |

## 数据来源

本文件结构与字段（`adcode`、`name`、`center`、`centroid`、`level` 等）与 [阿里云 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector) 提供的省级 GeoJSON 一致。DataV 地图数据上游来自**高德开放平台**，坐标系为 **GCJ-02**（国测局加密坐标）。

## 许可与使用边界

- **非商用演示**：本仓库作为开源静态演示，仅用于展示地图交互，符合一般学习与非营利展示场景。
- **商用或对外服务**：DataV / 高德地图数据通常**不允许**在未获授权的情况下用于商业产品或大规模公开服务。正式商用前须向[高德开放平台](https://lbs.amap.com/)或具备资质的地图数据供应商取得合法授权。
- **合规要求**：在中国境内公开展示地图须遵守《中华人民共和国测绘法》《地图管理条例》等法规，使用经审核的地图表示，并标注审图号（如适用）。
- **再分发**：随本仓库再分发 GeoJSON 几何数据时，请保留本说明；若上游条款禁止再分发，请改为在部署时自行从合法渠道获取并替换 `china.json`。

## 替换方式

若需更换地图数据源，将合法获取的省级 China GeoJSON 覆盖为 `china.json`，并同步更新本文件中的来源与许可说明。
